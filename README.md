# StepHaven

StepHaven is an iPhone walking game by Brody Richmond. A step recorded in Apple Health earns a point you can spend on your town. An indoor walk counts, and a friend can build alongside you in a shared town.

[Download StepHaven on the App Store](https://apps.apple.com/app/apple-store/id6817135263?pt=127985050&ct=github&mt=8) · [Official website](https://stephaven.app/)

![An afternoon in a StepHaven town](https://stephaven.app/press/files/village-afternoon.jpg)

- Price a bench, a gnome garden or a dog yard before your next walk. [Build planner](https://stephaven.app/build-planner/)
- See how the developer draws the town with Core Graphics and keeps villagers in sync across phones. [Illustrated development notes](https://stephaven.app/journal/drawn-in-code/)
- Get new guides in your feed reader. [Journal RSS](https://stephaven.app/journal/feed.xml)
- Find screenshots, a trailer and the developer’s contact details. [Press kit](https://stephaven.app/press/)

This repository publishes stephaven.app. When adding or revising a journal article, run `python3 .github/scripts/journal_feeds.py` and commit the generated feeds alongside the article.
